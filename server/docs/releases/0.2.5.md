# ConsoleCrypt Server 0.2.5

## Русский

- Исправлено удержание лимита параллельных вычислений Argon2: отменённый
  HTTP-запрос больше не освобождает слот до окончания фонового вычисления.
- Ответы OIDC ограничены 512 KiB при потоковом чтении, в том числе при
  отсутствии Content-Length. Слишком большой ответ отклоняется до накопления
  его целиком в памяти.
- Расширена проверка зависимостей через OSV/GHSA в дополнение к RustSec.
  Ошибка проверки останавливает выпуск.
- В CI обязательны PostgreSQL и отрицательные проверки совместного доступа,
  восстановления, replay-защиты и резервных копий. Отдельная регрессия проверяет,
  что один аккаунт не может подменить recovery-конверт другого даже при знании VAK.

Протокол и схема базы не меняются. Обновите образ до `0.2.5` и перезапустите
сервис обычным способом. Изменения уменьшают конкретные риски и не означают
отсутствия других уязвимостей.

## English

- Argon2 concurrency permits now remain held until a running computation
  actually finishes, even when its HTTP request is cancelled.
- Streamed OIDC discovery/token/JWKS responses are limited to 512 KiB,
  including responses without Content-Length.
- OSV/GHSA supplements RustSec dependency checks; tool failures block release.
- CI requires PostgreSQL-backed negative sharing, recovery, replay and backup
  tests. A regression rejects another account's recovery-envelope replacement
  even when the requester knows the vault access key.

The protocol and database schema are unchanged. Update the image to `0.2.5`
and restart the service. These changes address specific risks and do not claim
the absence of other vulnerabilities.
