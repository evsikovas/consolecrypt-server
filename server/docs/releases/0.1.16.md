# ConsoleCrypt Server 0.1.16

- Защита от входа с нового устройства (аудит безопасности 21.10.2026, S1),
  флаг `CC_DEVICE_PROTECTION_ENABLED` / Helm `config.deviceProtection.enabled`,
  по умолчанию выключен: письмо и событие `device_registered` о каждом новом
  устройстве со ссылкой «Это не я» (`POST /v1/devices/deny`), карантин нового
  устройства на 14 дней для отзыва доверенных устройств, «выхода из всех
  сессий» и смены пароля, ограничение выдачи материала разблокировки хранилища
  неподтверждённым устройствам (общие для реплик счётчики в PostgreSQL),
  отзыв ни разу не доверенных устройств при сбросе пароля.
- Сброс пароля аккаунта теперь всегда аннулирует прочие коды сброса и
  подтверждения почты, смена пароля — ожидающие коды сброса.
- `GET /v1/devices` отдаёт `trusted` и `quarantine_until`; `/v1/meta` —
  `capabilities.device_protection`.
- Миграция `0008_device_protection`: `devices.first_trusted_at` (заполняется по
  существующим device envelope), `devices.quarantine_lifted_at`,
  `device_deny_tokens`, `rate_counters`, `envelope_issuances`.

Протокол **1.7** только добавляет поля, событие и коды ошибок; клиенты
протокола 1.6 и старше продолжают работать. Сервер по-прежнему ничего не
расшифровывает.
