# ConsoleCrypt Server 0.1.15

- Добавлен тип зашифрованного общего объекта `db_connection` для подключений
  к базам данных. Подписи, права устройств, ревизии и отзыв доступа проверяются
  так же, как для подключений SSH и Kubernetes.
- Расширение включается отдельно через `CC_SHARED_DB_CONNECTIONS_ENABLED`
  или Helm `config.sharedDbConnectionsEnabled`. Возможность объявляется
  как `supports_db_connections`; список требует `include_db_connections=true`.
  Прежние клиенты продолжают получать только известные им типы.
- По умолчанию расширение выключено. Общий доступ и строгая проверка
  подписей запросов обязательны; отключение флага не удаляет шифротекст.

Протокол **1.6** обратно совместим с клиентами протокола 1.5. Сервер не
расшифровывает параметры подключений, не обращается к пользовательским базам
данных и не выполняет SQL. Новых миграций базы сервера нет.
