# ConsoleCrypt Server 0.2.3

## Документация для своего сервера

- **Полный справочник параметров** —
  [CONFIGURATION.md](https://github.com/evsikovas/consolecrypt-server/blob/main/docs/public/CONFIGURATION.md):
  все 184 ключа `CC_*` с путями в Helm, значениями по умолчанию, допустимыми
  значениями и назначением, порядок источников (переменные окружения, JSON-файл,
  Helm), какие значения секретные, все 18 лимитов запросов и команды
  администратора. Проверка в выпуске сверяет справочник с кодом в обе стороны.
- **Корпоративный вход по шагам** —
  [ENTERPRISE.md](https://github.com/evsikovas/consolecrypt-server/blob/main/docs/public/ENTERPRISE.md):
  Microsoft Entra ID, AD FS 2016+, Keycloak, Google Workspace, Okta, любой OIDC
  и Active Directory по LDAPS/STARTTLS; связывание аккаунтов при первом входе,
  таблица ошибок и решений, возврат к обычному входу.
- **Как задать любой параметр** —
  [HOSTING.md](https://github.com/evsikovas/consolecrypt-server/blob/main/docs/public/HOSTING.md):
  Docker Compose (`server.env` и приватный `compose.override.yaml`, секреты
  файлами), `docker run`, Helm, JSON-файл и systemd; готовые примеры — общие
  заметки и команды, Entra ID, LDAP, перевод лимитов в `enforce`, увеличение
  квот.

## Исправления

- Старое имя переменной `DATABASE_URL` снова работает: раньше сервер отбрасывал
  его до чтения, и действовал только `CC_DATABASE_URL`.
- `CC_TEAMS_ENABLED` принимает все формы логического значения, как остальные
  флаги: `true/false`, `1/0`, `yes/no`, `on/off`.
- Выпуски сервера объявляются в Telegram-канале автоматически.

Протокол и миграции не менялись (протокол 1.11, миграции до `0014`).

## English

### Self-hosting documentation

- **Full configuration reference** —
  [CONFIGURATION.md](https://github.com/evsikovas/consolecrypt-server/blob/main/docs/public/CONFIGURATION.md):
  all 184 `CC_*` keys with Helm paths, defaults, allowed values and purpose, the
  order of sources (environment, JSON file, Helm), which values are secret, all
  18 request limits and the admin commands. A release check keeps the reference
  and the code in sync both ways.
- **Corporate sign-in step by step** —
  [ENTERPRISE.md](https://github.com/evsikovas/consolecrypt-server/blob/main/docs/public/ENTERPRISE.md):
  Microsoft Entra ID, AD FS 2016+, Keycloak, Google Workspace, Okta, generic
  OIDC and Active Directory over LDAPS/STARTTLS; account linking on first
  sign-in, a troubleshooting table and switching back to standard sign-in.
- **How to set any parameter** —
  [HOSTING.md](https://github.com/evsikovas/consolecrypt-server/blob/main/docs/public/HOSTING.md):
  Docker Compose (`server.env` and a private `compose.override.yaml`, secrets as
  files), `docker run`, Helm, a JSON file and systemd; worked examples for shared
  notes and teams, Entra ID, LDAP, switching limits to `enforce` and raising
  quotas.

### Fixes

- The legacy `DATABASE_URL` variable works again; it used to be dropped before
  it was read, so only `CC_DATABASE_URL` took effect.
- `CC_TEAMS_ENABLED` accepts every boolean form like the other flags:
  `true/false`, `1/0`, `yes/no`, `on/off`.
- Server releases are announced in the Telegram channel automatically.

Protocol and migrations are unchanged (protocol 1.11, migrations up to `0014`).
