# ConsoleCrypt Server 0.1.18

- Общие заметки к общим объектам: участники общего хоста, подключения к базе
  данных или контекста Kubernetes ведут зашифрованные заметки к нему. Флаг
  `CC_SHARED_NOTES_ENABLED` (в Helm — `config.sharedNotesEnabled`),
  по умолчанию выключен; требует `CC_OBJECT_SHARING_ENABLED`. Объявляется как
  `supports_notes_v1` в `/v1/shares/capabilities`.
- Ключ заметок каждой эпохи доступа выдаёт и подписывает устройство владельца;
  каждую заметку подписывает устройство автора. Сервер проверяет членство,
  авторство, эпоху и подписи и хранит только шифротекст.
- Маршруты: `GET /v1/shares/{id}/notes`, `PUT /v1/shares/{id}/notes/keys`,
  `PUT|DELETE /v1/shares/{id}/notes/{note_id}`,
  `POST /v1/shares/{id}/notes/rekey`.
- Лимиты: 500 заметок на объект, до 288 KiB шифротекста на заметку.
- Миграция `0010_share_notes`: `shared_note_keys`, `shared_notes`.

Протокол **1.9** только добавляет маршруты и поле возможностей; клиенты
протокола 1.8 и старше продолжают работать. Сервер по-прежнему ничего не
расшифровывает.
