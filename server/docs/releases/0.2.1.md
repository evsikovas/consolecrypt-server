# ConsoleCrypt Server 0.2.1

- **Команды**: хранилища вида `team`, общие для нескольких аккаунтов
  (`/v1/teams/*`, `capabilities.teams`, `CC_TEAMS_ENABLED`, по умолчанию
  включено). Участники получают ключ хранилища через пользовательский конверт,
  запечатанный на их ключ участника команды; сервер ничего не расшифровывает.
- Подписанный журнал состава с цепочкой хэшей (генезис, добавление, смена роли,
  удаление, выход, передача владения, смена ключа): сервер проверяет порядок,
  подпись и права автора; клиенты проверяют весь журнал сами.
- Приглашения по почте (всегда `202`, сервер не раскрывает, есть ли аккаунт;
  не больше 20 в час на команду, срок 7 дней) и письмо приглашённому.
- Роли владелец, администратор, редактор, наблюдатель; наблюдателю отправка
  изменений запрещена (`403`, `details.reason = "team_role"`).
- Удаление участника отзывает его конверт и trust-маркеры устройств и требует
  смены ключа; смена ключа заменяет все конверты, ключ доступа и добавляет
  звено цепочки эпох.
- События WebSocket: `team_invitation_received`, `team_join_requested`,
  `team_membership_changed`, `team_key_rotated`, `team_removed`.
- Лимиты: 50 команд на аккаунт, 200 участников на команду (`CC_MAX_TEAMS_PER_ACCOUNT`,
  `CC_MAX_TEAM_MEMBERS`). `/v1/vaults` по-прежнему отдаёт только личные
  хранилища, поэтому старые клиенты команд не видят.
- Миграция `0012_teams`.

Протокол **1.10** только добавляет поля и маршруты; клиенты протокола 1.9 и
старше продолжают работать. Работает в обоих режимах входа (обычном и
корпоративном).
