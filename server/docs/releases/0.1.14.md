# ConsoleCrypt Server 0.1.14

- Добавлен отдельный тип зашифрованного общего объекта `kube_context` для
  подключений Kubernetes. Сервер проверяет подписи, права устройств, ревизии
  и отзыв доступа; содержимое kubeconfig и учётные данные остаются зашифрованными.
- Возможность включается через `CC_SHARED_KUBE_CONTEXTS_ENABLED` и объявляется
  как `supports_kube_contexts`. Для списка клиент передаёт
  `include_kube_contexts=true`; прежние клиенты получают только известные типы.
- Подключения Kubernetes поддерживают те же подписанные изменения, смену
  участников и подтверждение собственных устройств, что и SSH.
- Добавлены настройки Docker Compose и Helm. По умолчанию расширение выключено;
  для включения необходимы общий доступ и строгая проверка подписей запросов.

Wire-протокол остаётся **1.5**. Новых миграций БД нет. Обновление не переносит
хранилище и не меняет ключи шифрования существующих объектов.
