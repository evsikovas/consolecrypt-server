# ConsoleCrypt Server 0.1.17

- Удалить общий элемент может только владелец: удаление от редактора
  отклоняется с кодом `owner_only` (403), в том числе от старых клиентов,
  поэтому данные владельца не теряются (внутренний аудит безопасности, низкая
  критичность).
- Удалённый владельцем общий элемент можно восстановить в течение 30 дней:
  сервер хранит его последнее зашифрованное содержимое (`GET
  /v1/shares/deleted`), клиент публикует элемент заново с
  `restored_from`. После срока плановое обслуживание удаляет содержимое,
  подписанная отметка удаления остаётся.
- Получатель может выйти из общего доступа (`POST /v1/shares/{id}/leave`):
  все его устройства сразу теряют доступ, владелец видит выход в списке.
- Лимит в 1000 общих элементов считает действующие и восстанавливаемые
  элементы; удалённые после окончания срока больше не учитываются.
- Поиск получателя по адресу почты: `POST /v1/shares/recipients/lookup`
  с адресом в теле запроса, чтобы он не попадал в URL и журналы обратного
  прокси (`capabilities.recipient_lookup_post`). Прежний
  `GET /v1/shares/recipients?email=` оставлен для старых клиентов и помечен
  устаревшим.
- `/v1/meta` сообщает `capabilities.share_leave`, `share_restore` и
  `recipient_lookup_post`.
- Миграция `0009_share_owner_delete`: `shared_items.deleted_at`,
  `shared_items.restore_revision`, `shared_item_departures`.

Протокол **1.8** только добавляет поля, маршруты и код ошибки; клиенты
протокола 1.7 и старше продолжают работать. Сервер по-прежнему ничего не
расшифровывает.
