# ConsoleCrypt Server 0.1.13

- Исправлен поиск получателя общего доступа: email нормализуется так же, как
  при регистрации и входе, включая адреса с буквами разного регистра.
- Фоновое обслуживание удаляет только истёкшие nonce подтверждений входа и
  запросов; действующие маркеры защиты от повторного воспроизведения сохраняются.
- Release-образы AMD64/ARM64 публикуются только по совпадающему `vX.Y.Z` из
  истории `main`. Существующие image tags и опубликованные release assets
  не перезаписываются; release содержит digest, source commit и SHA-256 receipt.
- Подготовлена выкладка существующего Compose-сервиса по digest с проверкой
  health/version/source и явным откатом на прежний image ID. При отсутствии
  production SSH-конфигурации workflow показывает skipped, а не успешный deploy.

Wire-протокол остаётся **1.5**. Изменений схемы БД в этом patch нет.
Перед обновлением сохраняйте проверенную резервную копию БД и предыдущий образ.
